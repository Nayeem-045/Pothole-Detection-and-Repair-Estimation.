# Pothole-Detection-and-Repair-Estimation.
An end-to-end AI-based cloud framework for automated pothole detection and repair cost estimation. Uploads road images through a Django web interface, runs real-time inference using a YOLOv8 deep learning model, applies monocular depth estimation to measure pothole volume, and outputs a detailed repair cost report — all accessible from a central dashboard. Built with Python, OpenCV, PyTorch, and Bootstrap 5. Designed for smart city deployment, government road maintenance automation, and scalable infrastructure monitoring. Developed under the supervision of **Dr. D. Krishna Reddy**. Aligns with UN SDGs 3, 8, 9, and 11.
